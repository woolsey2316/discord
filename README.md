# discord
A MERN stack Discord application (MongoDB, Express, React, Node.js) has real-time chat, voice, and video functionality using Socket.io and WebRTC. It features MongoDB for message storage, Node/Express for the backend API, and React for a responsive interface. It has OAuth authentication, server/channel navigation, and user dashboards.

```
docker compose -f docker-compose.yml -f docker-compose.dev.yml --env-file .env.development up -d
```
